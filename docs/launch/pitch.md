# Pitch (DRAFT, owner review)

**One line**

Run a whole team of coding agents from one ticket board, on your own machine.

**Alternatives**

1. Tickets in, merged branches out: every agent works on its own git branch, and you stay in charge of the merge.
2. Claude Code, opencode and pi on one board, one daemon, your hardware, no third-party cloud in between.
3. Stop babysitting terminals. File a ticket, pick a role and a model, and watch the work from your desktop or phone.
4. A command post for coding agents, scripted in Lua so your process runs without you remembering it.
