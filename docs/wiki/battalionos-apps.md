# BattalionOS apps

Infantry AI is one app on BattalionOS. Apps (as opposed to plugins, which extend Infantry AI) are documented in the
BattalionOS repository, next to the code that runs them:

- [BattalionOS docs](https://github.com/SuperiorSoft-LLC/BattalionOS/tree/main/docs): what an app is (`apps.md`), the
  app ABI (`app-abi.md`) and the shell commands (`commands.md`).
- [BattalionOS README](https://github.com/SuperiorSoft-LLC/BattalionOS#readme): install and packaging.

To install BattalionOS itself, see [Install in BattalionOS](install-battalionos.md). To extend Infantry AI instead, see
[Plugins](plugins/overview.md).
